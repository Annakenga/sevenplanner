# Ресурсы проекта

Здесь хранятся материалы, которые помогают принимать решения по Seven, но не являются кодом приложения.

Рекомендуемые подпапки:

- `visual` — референсы, макеты, цвета, типографика и изображения.
- `product` — структура, сценарии и список функций.
- `technical` — схемы, исследования и технические решения.
- `content` — тексты интерфейса и пояснения для пользователя.

Для новых файлов лучше использовать понятные имена с датой или номером версии. Итоговые решения дополнительно фиксируются в документах проекта, чтобы они не потерялись среди черновиков.
