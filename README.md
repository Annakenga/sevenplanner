# Seven Planner

Seven — минималистичный недельный планер без регистрации и облачной базы данных.

## Основные принципы

- Задачи и настройки хранятся только в браузере пользователя через localStorage.
- Сайт публикуется через OpenAI Sites.
- Пользовательский фон обрабатывается и сохраняется только в браузере пользователя.
- Аналитика подключается после завершения основной разработки.
- В аналитику никогда не передаются тексты задач, заметок и другие пользовательские данные.
- Пользователь должен явно понимать, что очистка данных браузера может удалить содержимое планера.
