# Простой план работы над Seven

## 1. Организовать проект — сейчас

- Определить, какие отдельные чаты нам понадобятся.
- Сохранять результаты обсуждений в папке `resources`.
- Собрать все важные решения в одном месте.

## 2. Продумать продукт

- Определить, для кого создаётся Seven.
- Описать главный сценарий использования.
- Составить точный список функций первой версии.
- Отделить обязательные функции от идей на будущее.

## 3. Продумать структуру и дизайн

- Определить экраны и переходы между ними.
- Сделать схему интерфейса.
- Выбрать визуальный стиль, цвета и шрифты.
- Подготовить дизайн для компьютера и телефона.

## 4. Подготовить тексты

- Названия разделов и кнопок.
- Подсказки и пустые состояния.
- Сообщения об ошибках и удалении данных.
- Объяснение локального хранения и приватности.

## 5. Подготовить техническое задание

- Объединить функции, структуру, дизайн и тексты.
- Описать локальное хранение через IndexedDB.
- Предусмотреть резервную копию и восстановление данных.
- Зафиксировать требования для GitHub Pages.

## 6. Создать первую версию

- Навести окончательный порядок в папке проекта.
- Собрать интерфейс Seven.
- Реализовать функции планера.
- Подключить локальное хранение данных.

## 7. Проверить проект

- Проверить работу на компьютере и телефоне.
- Проверить сохранение данных после перезагрузки.
- Проверить резервное копирование и восстановление.
- Исправить ошибки и неудобные места.

## 8. Опубликовать

- Загрузить проект в репозиторий `Annakenga/seven-planner`.
- Настроить GitHub Pages.
- Проверить опубликованный сайт.
- Купить домен в Timeweb и подключить его к GitHub Pages.

## 9. Подключить аналитику

- Отслеживать посещения, возвраты и использование функций.
- Не передавать тексты задач и другие пользовательские данные.
- Проверить, какие данные реально отправляются.

## 10. Развивать Seven

- Собрать обратную связь.
- Исправлять найденные проблемы.
- Постепенно добавлять функции, которые не вошли в первую версию.
