# Архитектура Seven

## Зафиксированные решения

- Seven — статическое клиентское веб-приложение.
- Регистрации, аккаунтов и серверной базы данных нет.
- Основное хранилище — IndexedDB в браузере пользователя.
- GitHub хранит исходный код и публикует готовый сайт через GitHub Pages.
- Timeweb используется как регистратор домена и место настройки DNS, а не как хостинг приложения.

## Граница данных

В IndexedDB хранятся задачи, их состояние, настройки планера и служебная версия схемы данных. Приложение не должно незаметно дублировать эти данные во внешние сервисы.

## Важное ограничение

Данные привязаны к конкретному браузеру, его профилю и адресу сайта. Они не синхронизируются между устройствами. Очистка данных сайта, приватный режим или смена домена могут привести к тому, что пользователь не увидит прежние данные. Поэтому экспорт и импорт резервной копии входят в MVP.

## Обновления

Структура IndexedDB должна иметь явную версию и миграции. Новая версия Seven не должна удалять или перезаписывать существующие записи без отдельного подтверждения пользователя.

## Публикация

Приложение должно собираться в статические файлы, не требующие постоянно работающего сервера. Пути к ресурсам и навигация должны корректно работать как на временном адресе GitHub Pages, так и на собственном домене.
